# Asmia Mini App v2

Объединённая сборка:
- визуальный стиль — из `Asmia_MiniApp_v1`;
- выбор проекта, города и разделов — на основе рабочего `asmia_miniapp_prototype`;
- обработчики кликов реализованы через делегирование событий, без inline onclick.

## Файлы для GitHub Pages
Загрузите в корень репозитория оба файла:
- `index.html`
- `config.js`

`index.html` подключает `config.js` относительно корня сайта.

## Проекты и города
- Холдинг Аква: Краснодар, Ростов-на-Дону, Воронеж, Самара, Саратов.
- Перспектива СМ: Краснодар, Ростов-на-Дону.

## Важно
Это демонстрационный интерфейс. Реальные формы, авторизация, передача данных в MAX/бота, серверная логика и база данных пока не подключены.


## Дата последнего обновления плана визитов
Мини-приложение отображает дату и время последнего успешного импорта Excel. Перед выводом даты источник данных должен передать ISO-время в `window.VISIT_DATA_UPDATED_AT` либо `window.VISIT_DATA_META.updatedAt`. Значение должно записываться только после проверки файла, подтверждения администратором и успешного сохранения данных. Пока backend и загрузка Excel не подключены, интерфейс честно показывает «ожидает первой загрузки Excel».
