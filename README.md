# Asmia Mini App v2

Объединённая сборка:
- визуальный стиль — из `Asmia_MiniApp_v1`;
- выбор проекта, города и разделов — на основе рабочего `asmia_miniapp_prototype`;
- обработчики кликов реализованы через делегирование событий, без inline onclick.

## Файлы для GitHub Pages
Загрузите в корень репозитория оба файла:
- `index.html`
- `config.js`

`index.html` подключает `config.js` относительно корня сайта.

## Важно
Это демонстрационный интерфейс. Реальные формы, авторизация, передача данных в MAX/бота, серверная логика и база данных пока не подключены.


## Дата последнего обновления плана визитов
Мини-приложение отображает дату и время последнего успешного импорта Excel. Перед выводом даты источник данных должен передать ISO-время в `window.VISIT_DATA_UPDATED_AT` либо `window.VISIT_DATA_META.updatedAt`. Значение должно записываться только после проверки файла, подтверждения администратором и успешного сохранения данных. Пока backend и загрузка Excel не подключены, интерфейс честно показывает «ожидает первой загрузки Excel».


## Детализация по сотрудникам (v3)
На экране «План визитов» после общих показателей города выводится отдельный список сотрудников выбранного города. Для каждого сотрудника показываются план, факт, процент выполнения и индикатор прогресса.

- Список строится по всем данным сотрудника за проект и город, а не только по выбранной неделе. Поэтому сотрудник остаётся в списке, даже если в выбранном периоде у него нет строки или фактические визиты равны нулю.
- Для полного справочника действующих сотрудников backend может передавать `window.VISIT_EMPLOYEES` — массив объектов с полями `project`, `city`, `merchandiser` (или `employee` / `name`). Это позволит показывать и сотрудников, у которых пока нет ни одной строки в журнале визитов.
- Если отдельный справочник не передан, приложение использует уникальные ФИО из `window.VISIT_DATA` по всему загруженному массиву.
- `window.VISIT_DATA` остаётся массивом недельных записей с полями `project`, `year`, `month`, `week`, `city`, `merchandiser`, `plan`, `fact`.

Пример записи справочника:
```js
window.VISIT_EMPLOYEES = [
  { project: "Холдинг Аква", city: "Краснодар", merchandiser: "Иванов Иван Иванович" }
];
```
