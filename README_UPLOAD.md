# Asmia Mini App v5 — загрузка Excel

В этой версии загрузка выполняется **только через личный диалог MAX-бота Asmia**. Сотрудники могут просматривать общие данные в мини-приложении, но не могут загрузить или изменить Excel.

## Что входит в комплект

- `Asmia_v14_excel_upload.py` — обновлённый MAX-бот, основанный на рабочей v13; добавлен приватный сценарий импорта Excel.
- `index.html`, `config.js`, `visits-data.js` — файлы GitHub Pages мини-приложения.
- `План_визитов_Asmia_шаблон_с_сотрудниками.xlsx` — Excel с листами `Сотрудники`, `Данные`, `Инструкция`.
- `requirements.txt` — зависимости Python.

## 1. Подготовить GitHub token

Бот публикует проверенный файл `visits-data.js` в репозиторий `nischeta/miniapp`, ветка `main`. Для этого нужен отдельный токен GitHub:

1. Открой GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
2. Нажми Generate new token.
3. Repository access: Only select repositories → `nischeta/miniapp`.
4. Repository permissions → Contents: Read and write.
5. Создай токен и скопируй его. Не отправляй токен в чаты и никому не пересылай.

## 2. Настроить `.env`

Открой `C:\MAX_Bot\.env` и добавь строки (не удаляя существующий `MAX_TOKEN`):

```env
GITHUB_TOKEN=ВСТАВЬ_СЮДА_ТОКЕН_GITHUB
GITHUB_REPO=nischeta/miniapp
GITHUB_BRANCH=main
GITHUB_DATA_PATH=visits-data.js
```

Токен хранится только на компьютере, где работает бот. Он не попадает в GitHub Pages и не встраивается в Mini App.

## 3. Установить библиотеку для Excel

В командной строке Windows выполни:

```bat
py -m pip install openpyxl requests python-dotenv
```

## 4. Обновить бота

1. Останови работающий бот.
2. Сохрани копию текущего `Asmia_v13_miniapp_groups.py`.
3. Помести `Asmia_v14_excel_upload.py` в `C:\MAX_Bot`.
4. Запускай новую версию командой:

```bat
py Asmia_v14_excel_upload.py
```

Другие файлы бота и его JSON-настройки не удаляй. `BASE_DIR` остаётся `C:\MAX_Bot`.

## 5. Обновить Mini App в GitHub

В репозитории `nischeta/miniapp` (ветка `main`, корневая папка) замени:

- `index.html`
- `config.js`
- `visits-data.js`

Файл Excel в GitHub Pages загружать не нужно. Секретный токен в репозиторий не добавлять.

## 6. Как загружать Excel после настройки

1. Открой личный диалог с ботом Asmia.
2. Отправь `/upload` (можно сразу отправить `.xlsx` документом).
3. Бот проверит листы, колонки, проекты, города, даты, числовые значения и повторы.
4. Бот пришлёт сводку и ошибки, если они есть. До подтверждения опубликованные данные не меняются.
5. Если всё верно, отправь `/confirm`. Для отмены — `/cancel`.
6. Бот обновит `visits-data.js` в GitHub. GitHub Pages автоматически опубликует новую версию; обычно требуется несколько минут. Перезапусти Mini App, чтобы увидеть новые данные.

## Структура Excel

Обязательный лист `Данные` с колонками:

`Проект | Год | Месяц | Неделя | Город | Мерчендайзер | План | Факт`

Не переименовывай лист и колонки. Одна строка — один сотрудник за одну неделю.

Необязательный лист `Сотрудники`:

`Проект | Город | Мерчендайзер | Активен`

Он нужен, чтобы отображать действующих сотрудников даже при отсутствии строки в листе `Данные` за выбранную неделю. Значения `Нет`, `No`, `0`, `False`, `Неактивен` в колонке `Активен` исключают сотрудника из списка. Если листа нет, список строится по именам из `Данные`.

## Защита и сохранность

- Разрешённый администратор задан в коде бота: `ADMIN_USER_IDS = {42178893}`.
- Все остальные личные сообщения сотрудников продолжают обрабатываться прежним способом.
- Импорт проверяется до публикации; публикация происходит только после `/confirm`.
- При ошибке GitHub старый `visits-data.js` остаётся опубликованным.
- История успешных импортов и копии присланных Excel хранятся локально в `C:\MAX_Bot\asmia_uploads`.
- Секрет `GITHUB_TOKEN` не должен попадать в HTML, JavaScript, Excel или GitHub.

## Важно

В этой архитектуре GitHub Pages остаётся публичным статическим сайтом, поэтому данные, которые Mini App показывает сотрудникам, доступны всем, у кого есть ссылка. Ограничение «только администратор может обновлять» обеспечивается на стороне MAX-бота и GitHub token, а не скрытием кнопки в браузере.
