Asmia Mini App v6 — выбор текущего месяца и недели по умолчанию

Обновление:
- При первом открытии раздела «План визитов» выбирается текущий календарный месяц, если он есть в данных.
- Если в текущем месяце есть текущая ISO-неделя, она выбирается автоматически.
- Если текущей недели в данных ещё нет, выбирается «Весь месяц».
- Если данных за текущий месяц нет, выбирается самый поздний месяц, доступный в данных.
- Ручной выбор месяца и недели сохраняется при перерисовке панели.

Установка:
1. В репозитории GitHub открой корневой index.html.
2. Замени его файлом index.html из этого архива.
3. Выполни Commit changes.
4. Открой Mini App заново. При необходимости полностью закрой и повторно открой MAX.

Остальные файлы (config.js и visits-data.js) менять не нужно.
