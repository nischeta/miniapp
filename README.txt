Asmia — мини-приложение 1.18.4

Изменения:
1. В разделе «Зарплата» добавлены две CSV-выгрузки:
   - детальная по торговым точкам;
   - сводная по сотрудникам с разбивкой по сетям.
   Учитываются выбранные проект, город и месяц.
2. Добавлен блок «Тарифы и история изменений».
   Можно менять базовую сумму, основной норматив, специальное количество проверенных визитов,
   порог плана и условие сравнения (>= или >).
3. Изменение тарифа привязано к выбранному календарному месяцу и проекту.
   Другие месяцы не затрагиваются. Повторные изменения одного месяца сохраняются в истории.
4. Добавлен экспорт/импорт резервной копии тарифных настроек в JSON.

Важно о хранении тарифов:
Настройки хранятся в локальном хранилище браузера/WebView на устройстве, где их изменили.
Они не синхронизируются автоматически между устройствами или браузерами. Для переноса
используйте «Экспорт настроек» на первом устройстве и «Импорт настроек» на втором.
Перед очисткой данных приложения обязательно экспортируйте настройки.

Файл для публикации: Asmia_MiniApp_1.18.4_index.html
Бот не менялся: используется ранее выпущенная версия 2.2.3.
