Asmia Mini App 1.18.9

Основа: полный исходник Mini App 1.18.8. Существующие разделы визитов, отклонений, аналитики и расчёта зарплаты сохранены.

Изменения 1.18.9:
- Вместо «Дополнительный раздел» добавлен «Стандарты выкладки».
- Для «Холдинг Аква» подключён согласованный PDF «Рекомендации по выкладке ассортимента» (11 страниц).
- Для «Перспектива СМ» подключён отдельный PDF стандартов (16 страниц).
- Встроенный просмотр PDF работает непосредственно в Mini App.
- Реестр standards.json хранит текущую версию и архив каждой компании отдельно.
- Административная публикация выполняется через личный диалог MAX-бота, а не из браузера; секрет GitHub не размещается в Mini App.

Файлы для корня GitHub Pages:
- index.html
- config.js
- standards.html
- standards.json
- папка standards/ целиком

Важно: не удаляйте и не заменяйте visits-data.js, так как он содержит текущие данные визитов и тарифы. Загружайте только перечисленные файлы интерфейса и каталоги стандартов.
