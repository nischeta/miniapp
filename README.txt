Asmia Mini App v7

Изменение:
- Список сотрудников теперь формируется по записям выбранного месяца.
- Сотрудник, который начал работать только в ноябре, не отображается при выборе октября.
- При выборе отдельной недели в списке остаются сотрудники, работавшие в выбранном месяце; показатели у каждого считаются за выбранную неделю.
- Остальные функции v6 сохранены.

Установка:
Заменить только index.html в корне GitHub-репозитория nischeta/miniapp.
Файлы config.js, visits-data.js и бот менять не нужно.
