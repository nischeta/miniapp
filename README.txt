Asmia Mini App — v18

Исправление:
- На первом экране всегда доступны оба проекта: «Холдинг Аква» и «Перспектива СМ».
- Конфигурация config.js больше не может случайно скрыть один из этих проектов.
- Карточки выбора проекта адаптированы для мобильного экрана и занимают доступную ширину.

Установка:
1. Сделайте резервную копию текущего index.html.
2. Распакуйте архив.
3. Замените только index.html файлом из архива.
4. Не заменяйте config.js, visits-data.js и другие файлы данных.
5. Полностью перезапустите/обновите мини-приложение в MAX.

Проверки: синтаксис JavaScript и целостность ZIP.
